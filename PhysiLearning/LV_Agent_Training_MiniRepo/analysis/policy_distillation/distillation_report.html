Melanoma adaptive therapy · PPO policy distillation · supporting analysis

What did the treatment agent actually learn?

A three-level decision tree, fitted to the agent's treatment probabilities without being told any rule, finds one: start treatment when tumour burden passes about 1.5× its initial size, but after a treated interval continue only above about 2.2×. The agent gives short pulses.

CART regression onto P(treatment ON) · frozen Stable-Baselines3 PPO · LV tumour model · branch policy-distillation · 22–23 Oct 2026

Checkpoint
Method

Ask the agent, then fit the simplest tree that answers like it

The PPO agent sees an eight-number history: the normalised tumour burden B and the action already administered a, for the current and three previous decision points. It returns a probability of switching treatment ON. We record that probability on realistic histories and regress a shallow tree onto it.

step 1

Simulate

LV tumour model from the stage-2 config. 250 episodes, 60 decisions each.

step 2

Perturb

Flip 0, 5, 15 or 30% of executed actions so the agent visits off-orbit states.

step 3

Label

Every visited history gets the unchanged agent's P(ON).

step 4

Fit

CART regression, depth 3, ≥2% of samples per leaf. All 8 inputs, no hints.

step 5

Test

Held-out trajectories, plus 100 runs from new initial resistant fractions.

Identical trajectories were collapsed before splitting: the model is deterministic, so every unperturbed run is the same run. Train, validation and test never share a trajectory. This is ordinary policy distillation, not the VIPER algorithm.

Behaviour

The agent runs a tight pulse cycle

Under its own control from the configured starting tumour, the agent mostly treats for a single interval and then waits four or five. Burden climbs to just below the progression limit of 3× before each pulse.

The extracted tree

Burden first, then what was just given

The tree picks current burden as its first question and, on the high-burden side, whether the last interval was treated as its second. Both choices held in all 100 refits on resampled training trajectories, for both checkpoints.

The rule in one picture

Two curves, offset by treatment history

Plotting the agent's probability against current burden splits the held-out decisions into two families. After an untreated interval, P(ON) rises around 1.5×. After a treated interval, the same rise happens only near 2.3×. A two-threshold rule using just these two inputs captures most of the policy.

Fidelity

Nine in ten held-out decisions reproduced

Never treating already matches about 79% of decisions, because the agent is OFF most of the time. Balanced accuracy and switching F1 are therefore the informative scores: they ask whether the student treats when the agent treats and switches when the agent switches.

Ablation

Treatment history helps, by a checkpoint-dependent amount

Removing the four action inputs and refitting gives a burden-only tree. The gap between the two is clear for the agent used in the experiment and small for the paper candidate, where the agreement gain on the test set is not distinguishable from zero.

Closed loop

One wrong pulse can end the run

Because the agent keeps burden just under the limit, a single deviation at the wrong moment is often fatal. Flipping one action is enough to push the tumour past 3× within a few intervals. The same fragility applies to any stand-in controller, so per-decision fidelity is the primary result and closed-loop survival is a stress test.

Each controller run alone from 20 starting tumours (configured resistant fraction plus 19 drawn from 10⁻⁴ to 3×10⁻³). Outcomes swing between 0 and 100% under small changes to the student, such as depth 3 versus 4.

26 more agents

Seeds agree; refit tumour models vary

The same analysis was repeated for every agent in the bootstrap ensemble, each in the tumour model it was trained on. Five agents trained on the paper's LV parameters with different seeds land next to the two main checkpoints. Agents trained on bootstrap-refit parameters scatter more, but 18 of 20 still need more burden to continue than to start.

Before publication

Two checkpoints, one open question

The preserved paper candidate and the folder Agent_used_for_experiment are different networks trained with different PPO settings. They follow the same rule and agree on about 96% of decisions, but they are not interchangeable. Nothing in the repository records which one produced the experimental schedules. That needs to be confirmed before either is named in the manuscript.

Limitations

  • All trajectories come from the deterministic LV model with frozen parameters; only the starting resistant fraction was varied.
  • The experimental agent's own training config is not in the repository, so both checkpoints ran in the mini-repo stage-2 environment.
  • An axis-aligned depth-3 tree cannot cheaply express growth (Bt − Bt−1). No growth split does not mean the agent ignores growth.
  • Exploration only covers states near the agent's own orbit.
