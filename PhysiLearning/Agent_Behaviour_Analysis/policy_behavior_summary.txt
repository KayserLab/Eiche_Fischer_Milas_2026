Question Addressed
------------------
Is the selected experimental agent behaviorally representative of the ensemble
of bootstrapped agents, and what does the learned policy seem to do?

Short Answer
------------
Yes, qualitatively the selected experimental agent is representative of the
ensemble policy family.

It shows the same core learned structure as the bootstrap ensemble:
- high treatment probability after recent OFF histories
- lower treatment probability after recent ON histories
- strong dependence on recent treatment memory, not just on the scalar growth
  score

However, it is not the central or average ensemble member. Quantitatively, it
usually lies on the more treatment-permissive side of the ensemble,
especially for histories that already contain recent treatment.

Interpretation Of The Learned Policy
------------------------------------
The main signal is not a simple burden threshold. The policy has clearly
learned a history-dependent adaptive-therapy rule.

The strongest and most robust separation is between:
- recent OFF history, especially [0,0,0,0]
- recent ON history, especially [1,1,1,1]

This means the agent is not deciding only from the synthetic tumor-growth
summary. It is also using recent treatment history as an important state
variable.

In practical terms, the learned behavior looks like hysteresis:
- if treatment has recently been OFF, the policy becomes willing to switch ON
  relatively early
- if treatment has recently been ON, the policy is much less willing to keep
  it ON, even at larger growth scores

Important Caveat 1: Growth Score Is A Summary Axis
--------------------------------------------------
The x-axis is a derived score:
- growth = base + p_day + p_addition

Different synthetic burden histories can map to the same growth score.
Therefore, the same x-axis value can still correspond to a range of distinct
policy inputs.

So the growth axis is useful for visual summarization, but it is not a unique
state descriptor.

Important Caveat 2: Most Of The Stress-Test Grid Is Clipped
-----------------------------------------------------------
The stress-test grid was intentionally extended beyond the policy's trained
observation range.

The burden observations in the PPO input are clipped to the model observation
bounds before evaluation. On the current default 0 to 5 grid, about 77 percent
of probes per agent contain burden clipping.

This matters because:
- low to mid growth values are easier to interpret as near-distribution policy
  behavior
- the high-growth tail is better interpreted as stress-test behavior
- any plateau at large growth values is influenced not only by learned policy
  structure but also by observation clipping

Overall Conclusion
------------------
The selected experimental agent is a reasonable representative of the learned
policy class in the sense that it uses the same core logic as the ensemble:
strong treatment-memory dependence and clear separation between recent OFF and
recent ON histories.

However, it is not a median ensemble member. It sits consistently toward the
more treatment-permissive side of the ensemble, especially when recent history
already contains treatment.

So the most accurate summary is:
- representative in kind
- somewhat high-sided in degree

If these results are described in a manuscript or supplement, a defensible
phrasing would be:

"The experimental PPO policy exhibited the same qualitative hysteretic,
history-dependent treatment logic observed across the bootstrap-trained agent
ensemble, while tending to assign somewhat higher treatment-on probabilities
than the ensemble median, particularly after recent treatment exposure."
